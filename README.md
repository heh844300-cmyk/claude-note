## 專案簡介

Claude 筆記是一個跑在你自己 Windows 電腦上的小型伺服器（`mobile/server.js`，Node.js，零 npm 依賴），提供一個可以加到手機主畫面的網頁 App（PWA）：

```
輸入（文字／照片／分享）→ AI 整理成草稿 → 你修改或請 AI 重改 → 上傳到 Obsidian
                                                             └→ Agent 上網查資料、回答疑問、補知識庫筆記
```

AI 可以選 **Claude 訂閱**、**ChatGPT 訂閱（Codex CLI）**，或任何 **OpenAI 相容 API**（含 Gemini 免費金鑰、Ollama 本機模型）。
架構、資料流與安全設計請看 **[docs/技術說明.md](docs/技術說明.md)**。

## 核心功能（Features）

### ✍️ 整理

| 功能 | 說明 |
|---|---|
| **AI 整理草稿** | 文字、照片（白板、手寫、截圖），或從手機「分享」進來的內容，整理成摘要、重點、思路脈絡、待辦、待釐清問題 |
| **參考既有筆記** | 整理和查資料前，先從筆記庫找出相關的筆記當前提，不會重複問已經寫過的事 |
| **一次多主題自動拆篇** | 不相關的主題拆成多篇（預設最多 6 篇，`config.json` 的 `maxTopics` 可以改），另外建一篇「總覽」互相連結 |
| **筆記和知識庫分開放** | Obsidian 的 `Claude-Notes/` 分成兩類：`筆記/` 放每次整理好的筆記，`知識庫/` 放名詞、概念筆記（App 的「📒 筆記」裡也分成「📝 筆記」「📚 知識庫」兩頁）。舊版的筆記第一次啟動時會自動搬過去，寫了完整路徑的連結一起改好，改動前的檔案備份在 `.trash/版面調整前 …` |
| **名詞解釋拆成獨立筆記** | 解釋名詞的段落移到 `知識庫/`（預設每篇最多 5 個，`maxTerms` 可以改），原處留「摘要（詳見 → [[連結]]）」，和既有筆記去重。新拆出的名詞筆記，Agent 會再上網查證，補上「實際用途」：什麼情況會用到、具體例子、跟相近概念怎麼選。比較早的名詞筆記，到「📒 筆記」→「📚 知識庫」按「💡 補寫實際用途」一次補齊 |
| **到期與提醒** | 短期記事到期後移到 `.trash`；提醒用 Web Push 推播到手機和電腦 |
| **自訂整理規則** | 在 `prompt.local.md` 寫自己的規則（例如「標籤一律用中文」「不要思路脈絡」），整理、修改、更新筆記時都會照做；更新程式不會覆蓋 |

### 🔎 Agent 研究

| 功能 | 說明 |
|---|---|
| **回答待釐清問題、完成待辦** | 網路搜尋一手來源；完成的待辦自動打勾，查到的知識分成知識庫筆記 |
| **引用查證** | Agent 要列出答案依據的論點和引用的原文；系統實際打開每個來源，檢查原文在不在頁面上、撐不撐得起論點，在研究結果最後寫出「引用正確率」和需要留意的論點（說得比來源多、找不到原文、打不開） |
| **對照既有筆記** | 每條論點標明是沿用既有筆記、新增，還是推翻；查到的結果和你的筆記不一致時，會列出是哪一篇、原本怎麼寫、這次查到什麼（只提醒，不會自動改筆記） |
| **反證與信心** | 查到答案後換個立場再查一次，把反證和限制寫進答案；事實類的答案附上「信心：高／中／低」和理由 |
| **研究團隊（選配，預設關閉）** | 在設定頁開啟後，一次研究改由四個角色各自獨立上網查：文獻員找一手來源、調查記者替關鍵論點找兩個獨立來源、紅隊專門找反證、情報分析師評估信心；再由編輯整合，並列出「四方不一致的地方」。每次研究大約用 5 倍的 Agent 額度，這個模式不使用沙盒 |
| **回答後重查** | 在 App 裡回答「待釐清問題」，Agent 會帶著你的回答重新整理；已釐清的移到「已釐清」章節 |
| **灰色連結自動補** | 在 Obsidian 點一個還沒有筆記的 `[[名詞]]`，空白 1 分鐘後 AI 自動寫成完整筆記：它是什麼、**實際用途**（具體情境和例子）、跟你筆記的關係、來源 |
| **沙盒（選配）** | 需要安裝、測試軟體的待辦，在隔離的 WSL 發行版裡執行，碰不到你的電腦 |

### 🗂️ 管理

| 功能 | 說明 |
|---|---|
| **待辦統一管理** | 「待辦」分頁列出整個筆記庫的 `- [ ]`，有 `📅` 到期日的排前面，打勾直接改原筆記 |
| **持續追蹤** | 例會、長期專案設為主筆記；之後的進度自動變成「日期 名稱」每日紀錄並帶入前提；可在例會前 30 分鐘自動整理報告草稿並推播 |
| **用最新規則更新** | 整理規則改版後，一鍵把舊筆記重新整理成草稿，確認後才覆蓋（舊版先備份到 `.trash`） |
| **清除重複名詞** | 找出「其實是同一個概念」的知識庫筆記或灰色連結（例如 `PARA方法` 和 `PARA`），逐組確認後合併；每週自動掃一次 |
| **瀏覽整個筆記庫** | 網頁上唯讀瀏覽、搜尋所有 Obsidian 筆記，可點 `[[連結]]`、看圖片 |
| **🗺️ 本週（知識庫地圖）** | 「📒 筆記 → 🗺️ 本週」即時顯示：這週新增了幾篇（記錄、剪藏、知識庫…）、收集箱有沒有卡住、最近 30 天被新筆記連最多的筆記（大概就是你這陣子在想的事）、還沒想清楚的地方（筆記裡「矛盾或未想清楚之處」）。筆記庫裡的 `筆記/回顧/知識庫地圖` 每天更新一次 |
| **每週回顧** | 每週一 08:00 自動寫一篇 `筆記/回顧/YYYY-Www 週回顧`：一句話總結、這週在想什麼、值得決定的事、數字和清單，並推播。沒有新增也會推播一則，讓你知道排程有在跑；那天電腦沒開，這週之內開機時會補做 |
| **👤 查人** | 「🔍 搜尋」的「查人」：輸入名字，列出提到他的每篇筆記和那句話（不含信件和收集箱）；按「📇 整理成人物頁」由 AI 寫成 `知識庫/人物/名字`，每一點都附出處連結，引用的原話必須真的在筆記裡 |
| **🎨 三個版本** | 草稿頁按「給我三個版本」，AI 用三種寫法（例如條列、問答、敘述）各寫一次，內容相同，挑一個最像你的 |
| **🎨 品味與規則** | 設定頁的「品味與規則」：勾選 1～3 篇你覺得寫得好的筆記，AI 歸納出寫法規則；或「檢討我的修改紀錄」，從你在草稿「請 Claude 修改」和挑版本的紀錄找出你一直在改的地方。規則都先給你看、讓你改，按下確認才加到 `prompt.local.md` 的最後面 |

### 📚 學習

| 功能 | 說明 |
|---|---|
| **學習主題** | 每個主題一個資料夾（`Claude-Notes/學習/<主題>/`）：大綱、各章筆記、錯題本、教材；筆記裡的名詞連到你既有的筆記 |
| **大綱** | 有上傳教材（課本、講義）時照教材排；沒有的話 AI 先上網查證再排 |
| **大綱跟著教材長大** | 之後再上傳教材，AI 會自動對照現有大綱，列出「新增章節、補充重點、調整順序、合併、說法不同」的建議，勾選後才套用；已經上過的章節只會補充重點，不會被改名、移動或合併掉。補到已上過的章節會標 🆕，上課頁按「補上新內容」只補講新的部分；這一章已經有筆記的話，補充的內容會自動整理成草稿，確認後接在那篇筆記後面。每次調整都記在大綱的「大綱調整紀錄」 |
| **學習模式** | 一章一章上課（AI 知識＋網路查證），章節裡隨時追問（回答最後會出一個 🤔 小問題確認你懂了，在同一個輸入框回答，可以選「❓ 發問」「✍️ 回答小問題」或讓 AI 自動判斷；回答後只告訴你對不對，想多練按「🎯 再來一題」），小問題的回答和再來一題都收在原本的問題底下，每個問題可以摺疊（最新的展開、舊的收起），每章有小測驗；可以跨天接著上 |
| **應考模式** | 照你的教材出題：選擇、填空、問答、簡答、申論、名詞解釋，可設定題數、難度、範圍、仿照考古題風格、只練錯題 |
| **動態難度** | 5 個等級（基礎建立 → 大師挑戰）。程式依你每章的答題表現記錄等級：連對 2 題升一級、連錯 2 題降一級；應考出題選「🎯 自動」就照各章等級出題。上課的 🤔 小問題也會跟著升降級，答錯第一次先給提示讓你再試 |
| **作答提示** | 卡住時每題可以按「💡 給我提示」（最多 2 個），只給方向、不洩漏答案；結果會標出用了幾個提示 |
| **批改** | 選擇、填空由程式對答案；開放題由 AI 依參考答案要點打分數並指出缺漏 |
| **你的要求** | 主題的「教學要求」（例如多用生活例子、名詞附英文）上課、追問、出題、批改都會照做；出題時另外可以寫「這次的出題要求」，批改也照這個標準 |
| **錯題本** | 答錯或低於六成的題目自動記下；「只練錯題」答對後移到「已熟練」 |
| **讀書計畫** | 填考試日期後，章節排進每天、最後幾天留給模擬考；每天推播今天讀什麼，落後自動重排 |
| **懸浮筆記** | 上課和測驗時，筆記是一個懸浮視窗，邊讀邊記不用捲到頁尾：手機是從下面拉上來的抽屜（高度可以拖，鍵盤出現時會貼在鍵盤上面），電腦是可以拖曳、調整大小的面板，位置和大小會記住；按右下角的 ✏️ 打開、「▾ 收起」關掉，打字後自動儲存。選取教學內容或老師的回答，會出現「📌 記到筆記」（變成引用）和「🔑 加到線索」，不用自己複製貼上 |
| **數學公式** | 課程、問答、筆記、草稿裡的公式（`$…$`、`$$…$$`）會畫成真的公式：分數、上下標、根號、積分、矩陣都可以，跟在 Obsidian 裡看到的一樣。選取公式「記到筆記」時，存回去的是原本的公式寫法，整理成筆記後在 Obsidian 一樣能顯示。金額（`$5`）和程式碼不會被當成公式 |
| **問答視窗（電腦）** | 電腦上（視窗寬 1000px 以上）進入課程時，問答紀錄、小問題等級、發問和回答的輸入框、「再來一題」會放在左邊的一個小視窗裡，讀到一半就能發問，不用捲到最下面。課文會自動往右讓出位置；視窗可以拖曳、調整大小、收成左下角的 💬 按鈕（收起時有新回答會顯示數字），位置和大小會記住。手機和窄視窗維持原本排在課文下面的樣子 |
| **康乃爾筆記法** | 上課的筆記分成三個部分：「🔑 線索」（關鍵字、之後拿來考自己的問題）、「✏️ 筆記」（上課時記的內容）、「📝 總結」（上完用自己的話寫兩三句）。手機用分頁切換，電腦把面板拉寬就是左線索、右筆記、下總結的版面。只寫「筆記」也可以，跟以前一樣 |
| **整理成筆記** | 這一章結束時，筆記連同教學重點交給 AI 整理成草稿，確認後放進主題資料夾。你寫的線索會原樣列在筆記的「複習線索」一節（AI 不會替你回答），總結會放進摘要 |
| **上傳前審查** | 學習筆記整理成草稿後，AI 自動對照這一章的教學內容、教材並上網查證，列出事實或觀念錯誤（錯誤／不精確／待查），每條附原文、建議寫法和依據；可以勾選「套用修正」或標成「不用改」，還有沒處理的問題時上傳前會提醒 |

> 教材支援 HTML 網頁檔（含 Big5 編碼、Word 另存網頁）、文字檔、照片；PDF（含掃描檔）目前只有 Claude 能讀。

### 📖 每日英文閱讀

| 功能 | 說明 |
|---|---|
| **每天一篇真實的英文文章** | 每天固定時間（預設 07:30）Agent 上網找一篇跟你最近在研究的東西有關、任何人都能免費讀的英文文章，準備好就推播。主題來自最近 7 天新增或修改的筆記，也可以釘選幾個長期想讀的主題輪流出現 |
| **照你的程度** | 第一次使用先做 12 題分級測驗，定出 CEFR 等級（A2～C1）。文章比你的等級難時，會另外附一份「簡化版」；讀的時候也可以按「😵 太難了」當場產生 |
| **難度不只靠 AI 判斷** | Agent 找回來的 2～3 篇候選文章，程式都會用詞頻表（NGSL）和平均句長量一次難度，選最接近你等級的那一篇；量出來比你的等級難，也會附簡化版 |
| **點單字看意思** | 點文章裡任何一個英文單字，顯示它的詞性和中文譯義（線上翻譯 DeepL）。沒有設定翻譯金鑰時，改用小模型解釋句中的意思 |
| **整段中文對照** | 每段旁邊的 🌐 按鈕，按了才翻譯這一段，並存在文章裡，下次打開不用再翻。線上翻譯失敗時改用小模型翻譯，同樣會存下來 |
| **記得你查過的字** | 你點過的字會記下來，之後的文章再出現時用底線標出來；連續 3 次出現都沒有再點，就算學會了。準備單字表時，程式會先算出這篇有哪些字你可能不認識，一定列進去 |
| **讀完確認理解** | 3 題閱讀理解選擇題（題型有主旨、細節、推論、詞義、作者態度；你最常答錯的題型每篇都會出一題），交出後才看得到答案和說明；另外 AI 會對照你的舊筆記問一題（例如「這篇說 X，你的〈RAG〉筆記寫的是 Y，你怎麼看？」），你可以回答、寫自己的想法，或留白 |
| **等級自動調整** | 連續兩篇全對（而且讀的是原文）升一級；連續兩篇答對不到一半或按了「太難了」降一級。等級也可以自己改，或重新做分級測驗 |
| **整理成筆記** | 讀完自動整理成一篇中文筆記草稿，確認後放進 `Claude-Notes/英文閱讀/`，附兩個連結：App 裡存好的閱讀頁、原本的網站。英文原文只存在 App 裡，不會進 Obsidian |
| **接到你的研究** | 筆記連到的既有知識庫筆記，會在最後的「延伸閱讀與我的想法」加一行連回這篇（只追加，不改原本的內容），你寫的想法放在 AI 提問對照的那一篇；還沒有筆記的名詞照原本的規則拆成新的知識庫筆記 |
| **沒讀也沒關係** | 每天只準備一篇新的；沒讀的留在清單裡，想補再補 |
| **每週進步報告** | 每週日 20:00 推播：比較這週和上週的四個指標（查字密度、原文完讀率、理解正確率、文章難度），列出學會的字和最常答錯的題型，AI 寫一段下週的建議。連續兩週四個指標都沒有進步時，會提出一個要你決定的改變（等級降／升一級，或下一篇改成檢查點），你按「採用」才生效 |
| **檢查點文章** | 每 28 天，當天的文章改成檢查點：不能查字、沒有簡化版、不能 🌐，5 題涵蓋五種題型。答對 4 題以上升一級，答對 2 題以下降一級，用來校正等級，不只靠連對連錯 |
| **每週一個主題，三種立場** | 同一個主題這星期讀三篇：支持、反對、實作經驗；第三篇讀完會問你「現在站哪一邊」 |
| **對照你最近讀過的** | 文章開頭一句話，說明這篇和你最近 3 篇閱讀筆記哪裡矛盾或互補 |
| **英文摘要日** | 每週六，「你怎麼想」改成用英文寫三句摘要，AI 只指出最影響理解的一個錯誤並給改寫範例，不計分、不影響等級 |
| **事實查核（選配，預設關閉）** | 筆記上傳後，Agent 上網查證你連到的知識庫筆記有沒有和文章衝突；你確認後才會改筆記，舊版先備份到 `.trash` |

### ✉️ 信箱（Gmail）

| 功能 | 說明 |
|---|---|
| **全自動讀取** | Apps Script 每 10 分鐘把收件匣「主要」分類的**新信**（從設定那一刻起，舊信不讀、促銷和社群分類不讀）匯出，自動整理、直接寫進 `Claude-Notes/信件/`；分流成「可以忽略」的信不建筆記，只在 `信件分流紀錄.md` 加一行。有要回覆的新信時推播一次。要關掉就把 Apps Script 的 `AUTO_EXPORT` 改成 `false` |
| **貼標籤就整理** | 在 Gmail 把信貼上「筆記」標籤（隨時可以手動補讀任何一封，一定會留成筆記），大約十分鐘內整理成草稿（摘要、重點、待辦、待釐清的問題），你確認後才寫進筆記庫的 `Claude-Notes/信件/`（開了 `mailAutoUpload` 就直接寫進去）。個人帳號和學校帳號都可以接，多個帳號各放一個資料夾 |
| **自動分流** | 每封信的摘要第一行會寫「分流：要回覆／只需知道／可以忽略」，同時變成標籤（`#要回覆` 等），草稿上也看得到。你貼了標籤的信不會被丟掉，「可以忽略」只是標出來，方便你在 Obsidian 篩選 |
| **收據彙整** | 收據、發票、付款通知（標題有收據、訂單、付款成功等字，信裡有金額）不會每封一篇，而是每封一行寫進同一篇 `信件/收據彙整.md`（日期、商家、金額、用途、連回 Gmail）；金額必須真的出現在信裡才會寫，信用卡號不寫；有新增時推播一次（只有筆數） |
| **電子報變每日英文文章** | 你貼了標籤的英文電子報（信頭有 `List-Unsubscribe`、至少約 250 字的英文正文）不整理成信件筆記，而是放進文章池，下一次的每日英文就用它，不用上網找文章；一般週才用，檢查點和立場週照舊；公用電腦看不到這種文章 |
| **日期變成待辦和提醒** | 信裡明確寫出的日期變成 `📅` 到期日；行事曆邀請（`.ics`）的時間由程式讀出來、換成你的時區，活動前一小時提醒。沒有明確日期的事不會被猜一個日期；已經過去的、已取消的活動不提醒 |
| **不存密碼，唯讀** | 用你自己 Google 帳號裡的 Apps Script 把信匯出到 Drive 資料夾，Drive 桌面版同步到電腦，Claude 筆記只讀這個資料夾。權限只有三項：讀取 Gmail（唯讀）、管理這支程式自己建立的 Drive 檔案、設定自動執行；不能改、刪、寄信，也不能改標籤。步驟見 [docs/Gmail連接.md](docs/Gmail連接.md) |
| **信件是不可信的外部內容** | 信件整理用的 AI 呼叫沒有任何工具（讀不到你電腦的檔案、不能上網）；信裡要求 AI 做事的文字一律不照做（藏起來的文字、編碼的指示、假的系統訊息都會處理）；信件筆記不會觸發 Agent、不會被拿去當別的筆記的參考資料；遠端圖片會被移除；公用電腦看不到信件草稿 |
| **其他處理** | 驗證碼、卡號、密碼不寫進筆記；信的原文不複製進筆記庫，只留連回 Gmail 的連結；去掉引用的舊信和簽名；同一封信不會整理兩次（用 Message-ID 判斷）；同一個討論串的後續信會知道前一封是什麼 |

### 📎 網頁剪藏（Web Clipper）

| 功能 | 說明 |
|---|---|
| **看到好文章一鍵收進來** | 用 Obsidian 官方的瀏覽器外掛 Web Clipper 剪進筆記庫的 `Claude-Notes/收集箱/`，大約一分鐘內自動整理成一篇筆記，直接放進 `筆記/`，推播通知你 |

| **原文留著** | 剪下的全文移到 `收集箱/已整理/`，筆記最上面有原網址和「剪下的全文」連結；同一頁剪第二次不會產生第二篇筆記 |

| **名詞拆分比較少** | 剪藏筆記最多拆出 3 個名詞到知識庫（文章自己的用語大多不需要獨立成筆記），也不會自動上網補寫「實際用途」 |
| **可以關掉或改成先確認** | 設定頁的「📎 網頁剪藏」：開關、整理完要不要直接放進筆記庫（關掉就先留在「📥 草稿」）、檢查間隔、每次最多整理幾篇 |

## 安裝指南（Installation）

> 這是**私人**專案。請先到 email 或 GitHub 通知裡，接受專案擁有者寄給你的邀請。

**1. 安裝 Git**（裝好後關掉再重開 PowerShell）

```powershell
winget install --id Git.Git -e
```

**2. 下載專案**（第一次會跳出 GitHub 登入視窗，用受邀的帳號登入）

```powershell
cd $HOME
git clone https://github.com/heh844300-cmyk/claude-note.git ClaudeNote
```

**3. 執行安裝精靈**：打開 `ClaudeNote` 資料夾，**雙擊 `setup.cmd`**，照中文提示完成。精靈會：

- 檢查／安裝 Node.js，選擇 AI 並測試連線
- 選擇 Obsidian 筆記庫，寫入 `mobile/config.json`
- 設定開機自動啟動
- （選填）第 6 步設定手機與公用電腦連線、第 7 步建立 Agent 沙盒

**4. 開始使用**：瀏覽器打開 <http://127.0.0.1:8787>

> `127.0.0.1` 是這台電腦自己，連線不會離開電腦，所以用 http 就安全；從手機或公用電腦連進來時一律是 https。

手機的手動設定與細節：[docs/手機設定.md](docs/手機設定.md)

### 進階設定（`mobile/config.json`）

安裝精靈只會問必要的設定。下表的設定都可以在 App 的「⚙️ 設定・通知」→「🛠️ 功能開關與調整」直接改（馬上生效）；也可以直接編輯 `mobile\config.json`，在大括號裡加上想改的鍵，存檔後重新啟動伺服器（`mobile\stop-server.cmd` 再雙擊 `mobile\start-hidden.vbs`，或重新開機）。重新執行 `setup.cmd` 時，這些自己加的設定會保留。

| 鍵 | 預設 | 說明 |
|---|---|---|
| `maxTopics` | `6` | 一次輸入最多拆成幾篇主題筆記（2～20）；超過的主題併進最後一篇，不會丟掉 |
| `maxTerms` | `5` | 每篇筆記最多拆出幾個名詞解釋到 `知識庫/`（1～20），學習筆記也適用 |
| `termSplit` | `true` | 上傳後要不要把名詞解釋拆成獨立筆記 |
| `expandTerms` | `true` | 新拆出的名詞筆記要不要讓 Agent 上網補寫「實際用途」（每個名詞會多用一次 Agent） |
| `agentParallel` | `3` | 名詞筆記補寫「實際用途」可以同時跑幾件（1～6）；太多容易碰到 AI 的速率限制 |
| `agentVerify` | `true` | Agent 研究完要不要查證引用的來源、對照既有筆記（每次研究多用一次小模型，並由這台電腦打開引用的網頁） |
| `agentVerifyMax` | `12` | 每次研究最多查證幾條論點（1～30） |
| `agentTeam` | `false` | Agent 研究改用四個角色的研究團隊（每次研究大約 5 倍的 Agent 額度；需要安裝、測試軟體的待辦只會列出建議步驟） |
| `translatorProvider` | `"deepl"` | 線上翻譯的服務：`deepl`（DeepL API，免費方案每月 50 萬字元）或 `microsoft`（Azure Translator） |
| `translatorKey` | `""` | 翻譯服務的金鑰，用來點單字、整段中文翻譯。留空就不使用線上翻譯。**只放在 `config.json`，不會出現在設定頁** |
| `translatorRegion` | `""` | 只有 Azure Translator 需要，例如 `eastasia`；DeepL 留空 |
| `translateWords` | `true` | 點單字用線上字典查（需要金鑰）；關閉時改用小模型 |
| `translatePara` | `true` | 段落旁顯示 🌐 整段中文翻譯（需要金鑰） |
| `readingTime` | `"07:30"` | 每天幾點準備英文文章並推播（`HH:mm`；`""` 為不自動準備，只在按按鈕時找） |
| `readingReportTime` | `"20:00"` | 每週日幾點產生英文閱讀週報並推播（`""` 為不自動產生，仍可在每日英文頁手動產生） |
| `readingCheckpoint` | `true` | 定期把當天的文章改成檢查點文章 |
| `readingCheckpointDays` | `28` | 檢查點的間隔天數（7～90），從上一次檢查點（或分級測驗）算起 |
| `readingStances` | `true` | 每週一個主題，依序讀支持、反對、實作經驗三種立場 |
| `readingNewsletters` | `true` | 貼了標籤的英文電子報當每日英文的文章（關閉時電子報只整理成一般信件筆記） |
| `readingRelate` | `true` | 文章開頭一句話對照你最近 3 篇閱讀筆記（不多花一次 AI） |
| `readingFactcheck` | `false` | 筆記上傳後，Agent 查證連到的知識庫筆記有沒有和文章衝突（每篇多用一次 Agent 額度） |
| `readingSummary` | `true` | 每週一天把「你怎麼想」換成用英文寫三句摘要 |
| `readingSummaryDay` | `6` | 英文摘要是星期幾（0＝週日 … 6＝週六） |
| `mailEnabled` | `true` | 讀取 Gmail 匯出的信件；還沒設定 `mailAccounts` 時什麼也不會做 |
| `mailAccounts` | `[]` | 信箱清單，每個帳號一筆 `{ "name": "個人", "folder": "G:\\我的雲端硬碟\\ClaudeNote-Inbox", "email": "你的帳號@gmail.com" }`（`email` 選填）。**只放在 `config.json`，不在設定頁**；步驟見 [docs/Gmail連接.md](docs/Gmail連接.md) |
| `mailEveryMinutes` | `10` | 每幾分鐘檢查一次資料夾（5～120） |
| `mailMaxPerRun` | `5` | 每次檢查最多整理幾封（1～20；每封用一次 AI） |
| `mailKeepIgnored` | `false` | 全自動讀到、被分流成「可以忽略」的信也留成筆記（預設只在 `信件分流紀錄.md` 加一行；貼了標籤的信一定會留） |
| `mailAutoUpload` | `false` | 信件整理好後直接存進筆記庫的「信件」資料夾，不用在草稿確認（預設先變成草稿） |
| `mailNotify` | `true` | 收到新信時推播一次（只有封數，沒有主旨和寄件者） |
| `clipEnabled` | `true` | 整理 Web Clipper 剪進 `Claude-Notes/收集箱/` 的文章 |
| `clipAutoUpload` | `true` | 剪藏整理好後直接存進 `筆記/`（`false` 時先變成草稿） |
| `clipEveryMinutes` | `1` | 每幾分鐘檢查一次收集箱（1～60） |
| `clipMaxPerRun` | `3` | 每次檢查最多整理幾篇（1～10；和你自己的筆記排同一個佇列） |
| `weeklyReview` | `true` | 每週自動寫週回顧並推播 |
| `weeklyReviewDay`、`weeklyReviewTime` | `1`、`"08:00"` | 星期幾（1＝週一…7＝週日）、幾點產生；回顧到前一天為止的那一週 |
| `mapNote` | `true` | 在筆記庫保留 `筆記/回顧/知識庫地圖`（每天更新一次） |
| `updateCheckHours` | `6` | 每幾小時到 GitHub 檢查新版本（`0` 為關閉） |
| `dedupEveryDays` | `7` | 每幾天自動掃描重複的名詞筆記（`0` 為只用按鈕） |
| `fillAfterMs` | `60000` | 灰色連結建立的空白筆記，多久沒動就自動補寫（毫秒，`0` 為關閉） |
| `vaultExclude` | `[]` | 「🔍 搜尋」分頁不顯示的資料夾，例如 `["私人", "日記/2025"]` |

例：一次最多拆 15 篇、每篇最多拆 10 個名詞

```json
{
  "vault": "C:\\ObsidianVault",
  "maxTopics": 15,
  "maxTerms": 10
}
```

完整的設定清單見 [docs/技術說明.md](docs/技術說明.md#設定mobileconfigjson)。

## 使用範例（Usage）

### 網頁／手機 App

| 分頁 | 做什麼 |
|---|---|
| **✍️ 記錄** | 輸入文字、附照片，按「交給 Claude 整理」；有持續追蹤的筆記時可以選要接在哪一篇後面。第一次打開時，這裡會先顯示功能介紹卡 |
| **📥 草稿** | 檢查 AI 整理的結果、手動修改或「請 Claude 修改」，設定到期／提醒／Agent，再「上傳到 Obsidian」 |
| **📒 筆記** | 看筆記、讓 Agent 查資料、回答待釐清問題、設定持續追蹤、用最新規則更新；「📚 知識庫」裡可以清除重複名詞 |
| **✅ 待辦** | 整個筆記庫的待辦，打勾即完成 |
| **🎓 學習** | 建立學習主題、上傳教材、上課、應考出題、看錯題本和讀書計畫 |
| **🔍 搜尋** | 唯讀瀏覽與搜尋整個 Obsidian 筆記庫 |
| **⚙️ 設定・通知**（右上角） | 先選分類再調整：開啟提醒通知、手機和公用電腦的連線網址、管理登入的裝置、功能開關與調整、開關介面動畫、再看一次功能介紹 |

**例：每天記例會進度**

1. 打開例會的主筆記 →「📌 持續追蹤」→ 填名稱（例如 `例會進度`）、例會日子與時間 →「設為持續追蹤」
2. 之後在「✍️ 記錄」只要打：`今天把資料庫加上索引，明天研究辨識準確率`
3. 上傳後會存成 `2026-11-17 例會進度.md`，開頭連回主筆記；例會前 30 分鐘手機會收到報告草稿

**例：準備一場考試**

1. 「學習」→「＋ 新的學習主題」，填名稱（例如 `資料庫概論`）；需要的話在「教學要求」寫 `多用生活例子，專有名詞附英文`
2. 上傳老師給的講義（HTML、文字檔、照片；用 Claude 時也可以傳 PDF），考古題的種類選「考古題」→「產生大綱」
3. 填考試日期，每天會推播今天要讀的章節
4. 一章一章上課、追問；按右下角的 ✏️ 打開懸浮筆記邊讀邊記，看到重點就選取文字按「📌 記到筆記」，想到可以考自己的問題寫進「🔑 線索」，上完在「📝 總結」寫兩三句。讀完按「✅ 完成這章並整理筆記」；或直接「應考出題」：選題型與題數、難度選「🎯 自動」、勾「仿照考古題」
5. 交卷後看分數和解析，答錯的題目進錯題本，之後可以「只練錯題」；懸浮筆記裡寫的內容按「整理成筆記放進 Claude Note」就變成草稿
6. 老師又發了新講義：直接上傳到同一個主題，章節下面會出現「📝 大綱建議」，勾選要的再按「套用勾選的建議」；隨時也可以按「🔍 依教材檢查大綱」對照全部教材

**5 個難度等級**

| 等級 | 名稱 | 出什麼樣的題目 |
|---|---|---|
| Lv.1 | 基礎建立 | 最基本的定義與觀念辨認 |
| Lv.2 | 標準入門 | 基礎專有名詞、單一概念（新章節從這裡開始） |
| Lv.3 | 概念應用 | 情境應用、小型計算或推演 |
| Lv.4 | 進階變形 | 邊界條件、常見陷阱、多概念綜合 |
| Lv.5 | 大師挑戰 | 底層原理、方案取捨、設計與優化 |

### 網頁剪藏（Web Clipper）

1. 安裝 Obsidian 官方的瀏覽器外掛 [Web Clipper](https://obsidian.md/clipper)（Chrome、Edge、Brave、Firefox、Safari，iPhone 的 Safari 也有；Brave 直接從 Chrome 線上應用程式商店安裝，第一次剪時允許它開啟 Obsidian）。確認發行者是 **Obsidian.md**，Firefox 上有名字很像的非官方版本。
2. 打開外掛的設定：「General」的 Vault 選你的筆記庫；「Templates」的預設範本，把 **Note location** 改成：
   ```text
   Claude-Notes/收集箱
   ```
3. 看到好文章就按外掛的按鈕剪下來。大約一分鐘後會收到「📎 剪藏已整理」的推播，筆記在 `Claude-Notes/筆記/`，剪下的全文在 `收集箱/已整理/`。

> [!NOTE]
> 剪英文網頁之前，先關掉瀏覽器的自動翻譯，不然剪進來的會是機器翻譯（例如 agent 被翻成「代理商」）。翻譯交給整理的 AI 就好。
>
> 在手機上剪的文章，要等手機同步到這台電腦才會被整理。手機上的外掛是另外安裝的，忘了改存放位置也沒關係：外掛預設的 `Clippings/` 資料夾也會被整理。

### 線上翻譯（選配）

1. 到 [DeepL 開發者網站](https://www.deepl.com/pro-api) 註冊免費的 API 方案，複製金鑰（免費金鑰結尾是 `:fx`）。
2. 打開 `mobile\config.json`，加上 `"translatorProvider": "deepl"` 和 `"translatorKey": "金鑰"`，重新啟動伺服器。
3. 文章頁點單字會顯示譯義，段落旁會出現 🌐。

想用 Azure Translator：`translatorProvider` 改成 `"microsoft"`，金鑰和區域（例如 `"translatorRegion": "eastasia"`）從 Azure 的 Translator 資源複製。Azure 會顯示詞性和多個譯義，DeepL 只給一個譯義。

文章內容會送到所選的翻譯服務，所以只有你願意的時候才設定。台灣用語由程式（OpenCC 的台灣用詞表）在本機轉換。金鑰留在你的電腦，不會傳給 App 或手機。

### 每日英文閱讀

1. 打開「🎓 學習」分頁，按最上面的「📖 每日英文閱讀」，先做分級測驗（12 題，大約 5 分鐘；不確定的題目不要猜）。
2. 按「🔍 現在找一篇文章」（大約 2～5 分鐘），或等每天 07:30 的推播。想固定讀某些主題，在「⚙️ 等級與主題」填「釘選的主題」。
3. 讀文章：不懂的字直接點；整篇太難就切到「簡化版」，或按「😵 太難了」。
4. 回答底下的理解題，在「💭 你怎麼想？」寫一兩句（可以留白），按「✅ 讀完了，整理成筆記」。
5. 到「📥 草稿」確認筆記後上傳。筆記在 Obsidian 的 `Claude-Notes/英文閱讀/`，相關的知識庫筆記最後會多一行「延伸閱讀與我的想法」。

每週還會多幾件事（都可以在「⚙️ 設定・通知」→「🛠️ 功能開關與調整」關掉）：

- **每週日晚上 8 點**推播週報，點開是「📈 每週報告」頁；每日英文頁也可以隨時按「📈 產生這週的報告」。
- **檢查點**：28 天一次，當天的推播標明「檢查點文章」。這篇不能點字、沒有簡化版、沒有 🌐，答完會告訴你等級有沒有調整。想提早做，按「🎯 現在做一次檢查點」。
- **每週的主題**：一個星期的前三篇文章是同一個主題的三種立場，文章頁上方會標出「第幾／3 篇、觀點」。
- **事實查核**（要先打開）：筆記上傳後會推播結果；在文章頁看每一項的依據和來源，勾選「套用」才會改知識庫筆記。

需要 Agent 能上網搜尋（Claude、ChatGPT 訂閱都可以；API 金鑰或 Ollama 要另外設定 Tavily 或 Brave）。公用電腦模式不提供這個功能。

難度量測用的詞頻表是 [New General Service List 與 New Academic Word List](https://www.newgeneralservicelist.com)（Browne, Culligan & Phillips, 2013），以 CC BY-SA 4.0 授權，放在 `mobile/lib/wordlists/`（出處、授權和驗證結果見該資料夾的 README）。

### 自訂整理規則（`prompt.local.md`）

AI 整理筆記的基本規則在 `prompt.md`，每次更新都會換成新版，**請不要直接改它**。想加自己的規則，用記事本打開程式資料夾裡的 **`prompt.local.md`**（伺服器第一次啟動時會建立），寫在說明的下面：

```markdown
- 標籤一律用中文
- 「重點整理」每點不超過兩行
- 不需要「思路脈絡」這一節
```

- 存檔後下一篇筆記就生效，不用重新啟動；App 的整理、修改、「用最新規則更新」和電腦版的剪貼簿整理都會照做
- 和基本規則衝突時以你的為準，但 `TITLE`、`TAGS` 這些開頭的格式照舊（不然程式讀不懂 AI 的輸出）
- 這個檔案不進版控，`update.cmd` 不會覆蓋它

## 更新與版本

雙擊 **`update.cmd`**（執行 `git pull --ff-only` 後重新啟動伺服器）。要改 AI、金鑰、筆記庫等設定，重新執行 `setup.cmd`。

- 你自己的整理規則寫在 `prompt.local.md`，更新不會動到
- 如果你直接改過 `prompt.md`，更新時會先把你的版本另存成 `prompt.backup-<時間>.local.md`，再換成新版（以前這樣會讓更新失敗）。把裡面你自己加的規則搬到 `prompt.local.md` 就好，備份檔看完可以刪掉

- 網頁右下角顯示目前版本，例如 `V22.5 · 11/11`
- **更新後第一次打開 App 會跳出「更新內容」視窗**，列出這次改了什麼；點右下角的版本號隨時可以看，裡面有「以前的更新」和「檢查新版本」
- 伺服器每 6 小時檢查一次 GitHub；有新版本時右下角變成「🆕 有新版本」並**推播一次**（要先在右上角「⚙️ 設定・通知」開啟通知），視窗裡也看得到新版本會多什麼

每次的更新內容寫在 [`CHANGELOG.md`](CHANGELOG.md)。

版本號寫在根目錄的 [`VERSION`](VERSION)（格式 `大版本.小版本`）：

| 變動 | 升版方式 | 顯示 |
|---|---|---|
| 新增功能、更改架構 | 大版本 +1，小版本歸 0 | `V22` |
| 優化、修正、小功能 | 小版本 +1 | `V22.1` |

## 解除安裝

雙擊 **`uninstall.cmd`**，照中文提示操作：停止伺服器、刪除開機自動啟動、關掉這套程式開的 Tailscale 入口（不動你其他的 Tailscale 設定），最後刪除整個程式資料夾（包含設定、金鑰、草稿）。

- ✅ **你的筆記一律保留**：Obsidian 筆記庫裡的 `Claude-Notes`（筆記、知識庫）都不會被刪
- ⚠️ 還沒上傳的草稿會提醒你，刪除後就找不回來
- 安裝精靈裝的 Node.js、Tailscale、Codex CLI 等軟體不會自動移除，最後會列出移除指令

## 隱私與費用

- 你的筆記、草稿、金鑰都只存在你的電腦（`mobile\config.json`、`mobile\data\`），不會上傳到 GitHub
- 整理筆記、Agent 查資料時，相關內容會送到你選的 AI 服務；用 API 金鑰的話依該服務計費。Gemini 免費方案的內容可能被 Google 用於改善產品，詳見 [docs/用Gemini金鑰安裝.md](docs/用Gemini金鑰安裝.md)
- Agent 每次查詢都會用到額度，可以在草稿裡取消勾選「讓 Agent 查資料」
- Agent 只能上網搜尋和讀公開網頁，讀不到你電腦上的檔案，也連不到你的電腦或內部網路
