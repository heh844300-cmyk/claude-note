# 把 Gmail 連到 Claude 筆記

在 Gmail 把信貼上「筆記」標籤，大約十分鐘內，Claude 筆記會把它整理成一份草稿（摘要、重點、待辦、待釐清的問題），你確認後才寫進筆記庫。信裡的日期會變成待辦的 `📅` 到期日，行事曆邀請會變成提醒。

```
Gmail（貼標籤）→ 你帳號裡的 Apps Script 匯出成 .eml → Drive 資料夾 → Google Drive 桌面版同步到電腦
              → Claude 筆記讀這個資料夾 → AI 整理成草稿 → 你確認 → Claude-Notes/信件/
```

## 為什麼用這個方式

- **不用應用程式密碼，也不存任何密碼或令牌。** Google 對個人帳號和學校帳號越來越限制應用程式密碼；這個方式用你自己帳號裡的 Apps Script，不需要。
- **權限很小，而且由 Google 強制：** 讀取 Gmail（`gmail.readonly`，只能讀，不能改、刪、寄信、改標籤）、只能管理這支程式自己建立的 Drive 檔案（`drive.file`）、設定自動執行（`script.scriptapp`）。
- **伺服器不需要對外開任何入口。** Claude 筆記只讀你電腦上的一個資料夾。

## 信件內容會去哪裡

- 信件的文字會送到你在 Claude 筆記設定的 AI 服務（Claude、ChatGPT 或你的 API）。**哪些信會被處理**：你貼了「筆記」標籤的信，加上「全自動」：從你執行 `setup` 那一刻起，收件匣「主要」分類收到的新信（促銷、社群、討論分類的信，和以前的舊信都不會讀）。**全自動讀到的信，也會送給 AI 分流**，所以機密的信請讓它不要進「主要」分類，或把 Apps Script 最上面的 `AUTO_EXPORT` 改成 `false` 關掉全自動。
- 信的原文**不會**複製進筆記庫，筆記裡有一個連回 Gmail 的連結。
- 附件的內容不讀，只記下檔名。
- 信是任何人都能寄給你的外部內容，信裡要求 AI 做事的文字一律不會被照做。信件整理用的 AI 呼叫沒有任何工具（不能讀你電腦的檔案、不能上網）；信件筆記不會觸發 Agent 上網查資料，也不會被拿去當別的筆記的參考資料。

## 設定（每個 Gmail 帳號做一次）

### 0. 先刪掉之前的測試專案

之前用 `GmailApp` 測試的專案要求的是完整的 Gmail 權限。到 <https://script.google.com> 刪掉它，再到 <https://myaccount.google.com/permissions> 移除它。

### 1. 在 Gmail 建立標籤

建立一個叫「筆記」的標籤（名稱要一樣）。

### 2. 建立 Apps Script 專案

1. 用要匯出的帳號開 <https://script.google.com>，按「新專案」，命名為「Claude 筆記匯出」。
2. 左邊齒輪「專案設定」，勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。
3. 回到編輯器，打開 `appsscript.json`，把內容整個換成專案裡 `mail/appsscript.json` 的內容。
4. 打開 `程式碼.gs`，把內容整個換成專案裡 `mail/ClaudeNoteGmail.gs` 的內容。按 `Ctrl+S` 儲存。

### 3. 執行 `setup`

1. 上方的函式選單選 **`setup`**，按「執行」。
2. 會跳出授權畫面。出現「Google 尚未驗證這個應用程式」是正常的（程式是你自己的）：點「進階」→「前往…（不安全）」。
3. **請看授權畫面列出的權限，應該只有三項：**
   - 讀取你的電子郵件（唯讀）
   - 查看及管理這個應用程式建立的 Google 雲端硬碟檔案
   - 設定這個應用程式在你不在時自動執行
   如果出現「讀取、寫入、刪除、寄送電子郵件」或「所有的雲端硬碟檔案」，**不要同意**，告訴我。
4. 執行完，下方的執行記錄會寫「完成：資料夾『ClaudeNote-Inbox』…」。

### 4. 在 Gmail 貼一封信，看它出現

1. 隨便挑一封信貼上「筆記」標籤。
2. 在 Apps Script 選 `exportLabelled` 按「執行」（不用等十分鐘）。
3. 打開 Drive，應該有「ClaudeNote-Inbox」資料夾，裡面有一個 `.eml` 檔。
4. 在電腦上打開 Google Drive 桌面版的資料夾（例如 `G:\我的雲端硬碟\ClaudeNote-Inbox`），應該也看得到。

### 5. 告訴 Claude 筆記資料夾在哪裡

打開 `mobile\config.json`，加上 `mailAccounts`（路徑裡的反斜線要寫兩個）：

```json
"mailAccounts": [
  { "name": "個人", "folder": "G:\\我的雲端硬碟\\ClaudeNote-Inbox", "email": "你的帳號@gmail.com" }
]
```

- `name`：這個帳號的名字，會出現在草稿和筆記上。
- `email`：選填，筆記裡的「在 Gmail 開啟」連結會用它指定帳號。
- 有第二個帳號（例如學校）：在 Google Drive 桌面版新增那個帳號，到檔案總管找到它的「ClaudeNote-Inbox」資料夾路徑，再加一筆。**第二個帳號會掛在哪個磁碟機，要看你電腦上實際顯示的，不要猜。**

存檔後重新啟動伺服器（`mobile\stop-server.cmd`，再雙擊 `mobile\start-hidden.vbs`）。

### 6. 確認

「⚙️ 設定・通知」→「✉️ 信箱」會顯示每個帳號的資料夾狀態、有幾個檔案、處理了幾封；按「現在檢查一次」。有信時，「📥 草稿」會出現標著 ✉️ 的草稿。

## 第一次安裝後，請回報這三件事

這三點我在你的帳號上還沒實測過：

1. 授權畫面列出的權限是不是只有上面那三項？
2. 在 Gmail 貼標籤、執行 `exportLabelled` 後，有沒有出現錯誤？（執行記錄裡的訊息）
3. `.eml` 檔真的出現在電腦的 Drive 資料夾裡嗎？

## 全自動讀取

- Apps Script 每 10 分鐘把「主要」分類的新信也匯出（檔名有 `-auto-`），Claude 筆記自動整理、直接寫進 `信件/`（要開 `mailAutoUpload`，我的設定是開的）。你不用貼標籤。
- **從 `setup` 那一刻開始算**：舊信一律不讀（時間記在 Apps Script 的指令碼屬性 `autoSince`）。
- 分流成「可以忽略」的信（廣告、群發、和你無關）**不留成筆記**，只在 `信件/信件分流紀錄.md` 加一行（日期、寄件者、主旨、連回 Gmail 的連結）。想補成筆記：在 Gmail 貼上「筆記」標籤，下一次匯出就會補成筆記。設定頁的「自動讀到的『可以忽略』的信也留成筆記」可以改成都留。
- 你自己貼了「筆記」標籤的信，一定會留成筆記，不管分流是什麼。
- 有「要回覆」的新信時推播一次（只有封數）；收據照舊一行一筆。
- 想關掉全自動：把 Apps Script 最上面的 `AUTO_EXPORT` 改成 `false`，儲存即可（不用重新執行 `setup`）。想改範圍（例如也要「促銷內容」裡的訂閱信）：改 `AUTO_QUERY`，用 Gmail 的搜尋語法。
- **更新方式（兩個帳號都要）**：把新版 `mail/ClaudeNoteGmail.gs` 整份貼進 `程式碼.gs` 取代，存檔，再執行一次 `setup`（會記下開始時間，不會重複匯出已經匯出的信）。

## 日常使用

- 在 Gmail 貼「筆記」標籤 → 最多約十分鐘（Apps Script 每十分鐘一次，加上 Drive 同步）→ 草稿。想馬上看，在 Apps Script 手動執行 `exportLabelled`，再到「✉️ 信箱」按「現在檢查一次」。
- 草稿確認後上傳，筆記在 `Claude-Notes/信件/`。待辦出現在「待辦」分頁；有日期的事會有提醒。
- 同一封信不會整理兩次（用信件的 Message-ID 判斷）；同一個討論串的後續信，整理時會知道前一封是什麼。
- 信件筆記不會出現在 App 的「📒 筆記」分頁，用「🔍 搜尋」或 Obsidian 看。

## 收據、電子報和分流

- **收據**：標題有「收據、發票、訂單、付款成功」之類的字、信裡又有金額的信，不會每封一篇筆記，而是一行一筆記在 `Claude-Notes/信件/收據彙整.md`（日期、商家、金額、用途、連回 Gmail 的連結）。信用卡號不寫；金額一定要是信裡真的有的。有新增時推播一次，只說筆數。
- **英文電子報**：貼了標籤、信頭有「取消訂閱」資訊、正文是夠長（約 250 字以上）的英文時，不整理成信件筆記，而是放進每日英文的文章池，之後的某一天直接當那天的文章（不用上網找）。檢查點和固定主題的一週不會用它。在設定頁的「📖 每日英文」可以關掉（`readingNewsletters`）。
- **分流**：一般的信，摘要第一行會寫「分流：要回覆／只需知道／可以忽略」，也會變成標籤。你貼了標籤的信不會被丟掉。
- 這三種都由程式根據信頭和內容判斷，所以 Apps Script 不需要再更新。

## 日期和行事曆

- 行事曆邀請（`.ics`）的時間由程式讀出來，換成你電腦的時區，AI 不會自己猜。活動前一小時提醒（全天的活動在前一天晚上 8 點）；已取消的活動、已經過去的活動不提醒；看不懂的時區不提醒。
- 一般的信，信裡明確寫出日期才會有 `📅`；「明天」「下週五」依信寄出的時間換算；沒有明確日期的事不會被猜一個日期。

## 限制

- 單封信超過 8 MB 不匯出。信件正文只取前 12000 字。
- 附件不讀。轉寄的信（以附件形式）會讀一層。
- 刪掉 Drive 資料夾裡的 `.eml` 檔，下次 Apps Script 會再匯出同一封（Claude 筆記用 Message-ID 去重，不會再建立草稿）。Claude 筆記不會刪除或搬動那個資料夾裡的任何檔案。
- 學校帳號可能被管理員限制 Apps Script 或 Drive 桌面版；做不到的話，這個帳號沒有替代方案。

## 停用和移除

- 暫停：「⚙️ 設定」關掉「讀取 Gmail 匯出的信件」。
- 停止匯出：在 Apps Script 執行 `removeTrigger`。
- 完全移除：刪掉 Apps Script 專案、到 <https://myaccount.google.com/permissions> 移除它，再刪掉 Drive 的「ClaudeNote-Inbox」資料夾。
