# 手機設定（選配）

手機透過 **Tailscale** 安全地連回家裡的電腦。Tailscale 個人使用免費，連線經過加密，只有你登入同一個帳號的裝置連得到，不用在路由器開任何連接埠。

## 1. 電腦和手機都裝 Tailscale

1. 電腦：`winget install --id tailscale.tailscale -e`，安裝後登入（可用 Google、GitHub、Microsoft 帳號）
2. 手機：Play 商店或 App Store 搜尋「Tailscale」，用**同一個帳號**登入
3. 到 https://login.tailscale.com/admin/dns 確認 **MagicDNS** 和 **HTTPS Certificates** 都已開啟

## 2. 讓手機連得到筆記伺服器

在電腦的 PowerShell 執行（只開放給你自己的 Tailscale 網路）：

```
& "C:\Program Files\Tailscale\tailscale.exe" serve --bg 8787
& "C:\Program Files\Tailscale\tailscale.exe" serve status
```

`serve status` 會顯示一個網址，像 `https://電腦名稱.xxxx.ts.net`。

**不要**用 `tailscale funnel` 開 443 埠，那會把不需要登入的入口公開到網路上。

## 3. 寫進設定

打開 `mobile\config.json`，加上（換成你的網址）：

```json
"publicUrl": "https://電腦名稱.xxxx.ts.net"
```

然後重新啟動伺服器：執行 `mobile\stop-server.cmd`，再雙擊 `mobile\start-hidden.vbs`。

## 4. 手機上使用

1. 手機開著 Tailscale，用瀏覽器（Android 用 Chrome）打開上面的網址
2. 瀏覽器選單 →「加到主畫面」，就像一個 app
3. 在「新增」頁按「開啟通知」，就能收到提醒和 Agent 完成的推播
4. Android 可以從其他 app「分享」文字或圖片到 Claude 筆記

## 5.（進階）不開 VPN 的公開網址＋QR code 登入

想在沒裝 Tailscale 的裝置（例如借來的電腦）上用：用 Tailscale Funnel 開一個公開網址，進去要先用信任的手機掃 QR code 核准。

1. `config.json` 加上：`"publicPort": 8788, "funnelUrl": "https://電腦名稱.xxxx.ts.net:8443"`，重新啟動伺服器
2. 執行：`& "C:\Program Files\Tailscale\tailscale.exe" funnel --bg --https=8443 http://127.0.0.1:8788`
   （第一次可能要在 Tailscale 後台允許 Funnel）
3. 打開 `https://電腦名稱.xxxx.ts.net:8443`，用開著 Tailscale 的手機掃畫面上的 QR code、按「允許登入」
4. 登入畫面預設勾選「這是公用電腦」：只能瀏覽（伺服器會拒絕任何新增、修改、核准其他登入、開推播）、2 小時後失效、閒置 15 分鐘自動登出（關掉分頁後最慢 15 分鐘失效，有些瀏覽器會在重開時恢復登入，所以用完請按「登出」）；取消勾選才是個人裝置（30 天有效）
5. 「筆記庫」分頁可以唯讀瀏覽整個筆記庫。不想從外面看到的資料夾，在 config.json 加上 `"vaultExclude": ["私人", "日記"]`（資料夾路徑，重新啟動伺服器生效）
6. 「新增」頁下方可以看到、移除所有登入過的裝置；手機收到「公用電腦已登入」推播時，也可以從這裡把它踢掉
7. 關閉：`& "C:\Program Files\Tailscale\tailscale.exe" funnel --https=8443 off`

## 6.（選配）手機上也有完整的 Obsidian 筆記庫

用 **Syncthing** 讓電腦和手機的筆記庫互相同步（免費、不經過雲端）：

1. 電腦：`winget install --id Syncthing.Syncthing -e`；用 `syncthing\start-syncthing.vbs` 在背景啟動，並把它複製到開機啟動資料夾（Win+R 輸入 `shell:startup`）
2. 電腦打開 http://127.0.0.1:8384 ，第一次會要求設定帳號密碼；新增資料夾，路徑選你的筆記庫
3. 手機：安裝 **Syncthing-Fork**（建議從 F-Droid 安裝）和 **Obsidian**
4. 兩邊互相加入對方的「裝置 ID」，把筆記庫資料夾分享給手機，手機上選一個新的空資料夾接收
5. 手機的 Obsidian 選「開啟資料夾作為保存庫」，選那個資料夾
6. 建議在筆記庫根目錄放一個 `.stignore`，內容：
   ```
   .obsidian/workspace.json
   .obsidian/workspace-mobile.json
   ```
   避免兩邊的分頁版面互相衝突

手機和電腦同時改同一篇筆記時，會多一個 `.sync-conflict` 檔案，兩個版本都會保留。
